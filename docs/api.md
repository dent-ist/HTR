# HTR API (M2)

Base URL `http://127.0.0.1:8000` (loopback only). Interactive docs generated by FastAPI: `/docs` (Swagger UI) and
`/openapi.json`. This page is the human summary. All bodies are JSON unless noted; errors are
`{"detail": "..."}` (422 validation errors carry a list of `{loc, msg, type}`).

Status codes used: 200, 201 (created), 202 (job enqueued), 204, 404 (not found), 409 (conflict with current state),
413 (upload too large), 415 (not PNG/JPEG/TIFF), 422 (invalid input).

Coordinates: every point is `[x, y]` in **working-copy pixels** (the image served by `/pages/{id}/working`), integers
(floats are rounded), and must lie inside the page. A polygon has at least 3 points, a baseline at least 2.

| Method | Path | Notes |
|---|---|---|
| POST | `/documents` | `{"name": "..."}` -> 201 document `{id, name, imported_at, page_count}` |
| GET | `/documents` | list |

## Pages

| Method | Path | Notes |
|---|---|---|
| POST | `/pages` | multipart: `file` (PNG/JPEG/TIFF, extension and content checked, size limit `HTR_MAX_UPLOAD_MB`, default 100) and `document_id`. 201 with the page; **200 with `"duplicate": true`** if the identical file (SHA-256) was imported before. Original stored untouched in `data/originals`, working copy in `data/working`, import warnings recorded. |
| GET | `/pages` | list with `status` and counts. Filters: `?document_id=`, `?status=unsegmented\|segmented\|partially_transcribed\|done` |
| GET | `/pages/{id}` | page metadata plus `lines` in reading order |
| GET | `/pages/{id}/original` | the untouched original file |
| GET | `/pages/{id}/working` | the working copy (PNG) all coordinates refer to |
| POST | `/pages/{id}/segment` | enqueue a `segment` job -> 202 job. Body optional `{"force": false}`. 409 if a segment job for the page is already queued/running, or if the page has manually transcribed / ground-truth lines and `force` is not set (re-segmenting replaces all lines). |

Page object: `id, document_id, original_filename, status, width, height` (working copy), `original_width,
original_height, dpi, line_height_px, scale, skew_deg, deskewed, warnings, sha256, imported_at, segmented_at,
image_url, original_url`, and in lists/detail `line_count, ground_truth_count, ignored_count`.

Status: `unsegmented` (never segmented); `segmented` (no active line is transcribed yet); `partially_transcribed`
(some active line is ground truth or has manual text); `done` (at least one active line and all active lines are ground
truth). Ignored lines are not counted; predictions alone do not count as transcribed.

## Lines

| Method | Path | Notes |
|---|---|---|
| PATCH | `/lines/{id}` | partial update, any of `text, polygon, baseline, ignored, is_ground_truth, index`. See rules below. |
| DELETE | `/lines/{id}` | 204; later lines are renumbered |
| POST | `/pages/{id}/lines` | `{baseline, polygon, text?, ignored?, index?}` -> 201 line. Page must be segmented (409 otherwise). Default index = append. |
| GET | `/lines/{id}/crop.png` | working copy cropped to the polygon's bounding box |

Line object: `id, page_id, index` (0-based reading order), `baseline, polygon, text, text_source` (`manual`,
`predicted` or null), `confidence` (predictions only), `is_ground_truth, ignored, crop_url`.

PATCH rules: setting `text` sets `text_source = "manual"` and clears `confidence` (empty text clears the source);
text is stored exactly as sent (diplomatic), max 2000 characters, no control characters; `is_ground_truth: true`
requires non-empty text; `index` moves the line to that position and shifts the others in one transaction (this is the
reorder operation); `null` values and unknown fields are rejected.

Every line change (and every segmentation) rewrites the page's PAGE-XML in the same operation as the DB commit; if the
rewrite fails the change is rolled back. See "PAGE-XML sync" in the README.

Not implemented (M3): split and merge of lines.

## Jobs

| Method | Path | Notes |
|---|---|---|
| GET | `/jobs/{id}` | `{id, type, status, payload, progress (0-1), error, result, created_at, started_at, finished_at}` |
| GET | `/jobs` | newest first. Filters `?status=`, `?type=`, `?limit=` (default 100, max 500) |
| POST | `/jobs/{id}/cancel` | cancels a **queued** job; 409 once it has started |

Statuses: `queued`, `running`, `succeeded`, `failed`, `cancelled`. One job runs at a time, in order. Job types:
`segment` (implemented), `predict` and `train` (registered; fail with "not implemented until M4"). A job left
`running` by a crash is marked `failed` ("interrupted") on the next start.
